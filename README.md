# YogaNest - Full-Stack Wellness Platform

A modern, production-ready web application for guided yoga modules, personalized recommendations, and AI-based posture tracking.

## 🚀 Features

- 10+ guided yoga modules categorized by type
- User authentication with JWT
- Personalized yoga recommendations using AI logic
- Simulated posture tracking with feedback
- Responsive design (mobile, tablet, desktop)
- Dark mode support
- Progress tracking and favorites

## 🛠️ Tech Stack

**Frontend:**
- React.js with Hooks
- Tailwind CSS
- React Router

**Backend:**
- Node.js with Express.js
- MongoDB with Mongoose
- JWT Authentication
- Bcrypt for password hashing
